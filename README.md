# Diploma Exam Prep

Study notes for the Buddhism Diploma exams.

- **[Home](https://chujieying.github.io/buddhism-diploma/)**: what the site is for, the five papers at a glance, how to study with it, and a friendly warning about spiritual materialism.
- **[Pāli](https://chujieying.github.io/buddhism-diploma/pali.html)**: everything for the Pāli paper on one page: simple lessons with memory tricks, every chart (alphabet, declensions, conjugations, pūjā and vandanā) with a tap-to-reveal quiz mode, flashcards and practice tests.
- **[Early Buddhism](https://chujieying.github.io/buddhism-diploma/eb.html)**: Early Buddhism (Basic Doctrines) coach. A big-picture map built on the Four Noble Truths, a lesson per exam topic (including dependent origination, asked every year) with simple explanations and memory tricks, flashcards, a quiz and a timed essay drill with 40 questions from the 2020–2024 papers.
- **[Geo Expansion](https://chujieying.github.io/buddhism-diploma/geo.html)**: Geographical Expansion of Buddhism, one lesson per exam question with explain-like-I'm-5 boxes, mnemonics, a map, answer outlines, flashcards, a quiz and a timed essay drill using past-year questions.
- **[Overlaps](https://chujieying.github.io/buddhism-diploma/overlaps.html)**: a slide deck for the six topics that appear in more than one paper (five precepts, ten deeds and kamma, Four Noble Truths and the Path, five aggregates, the Second Council split, mindfulness). Mind maps and memory tricks first, then a full model answer for each with what to add for each paper.
- **[Decks](https://chujieying.github.io/buddhism-diploma/decks.html)**: one revision deck per paper (Early Buddhism, Social Dimensions, Geo Expansion, Counselling, Pāli), built from the principal's exam questions. Each question has a mind map, memory tricks and an answer skeleton, with a cheat sheet of every memory trick at the end.
- **[Counselling case studies](https://chujieying.github.io/buddhism-diploma/case-co.html)**: practice for the Psychology and Counselling case-study question ("identify the aspects of suffering and the underlying causes"). The event–feeling–clinging and ignorance–craving–aversion framework from Lessons 3, 4 and 10 as a cheat sheet, the answer layout from the class sample, a cue-spotting table, tips for the Mr. A sample, and three new practice vignettes with full model answers.
